# My Task List

Name: Jacqueline Magawa

# Description

My Task List is a small interactive web page that lets a user keep track
of things they need to do. A user can type in a task, choose a priority
(Low, Medium, or High), and add it to a running list. Each task on the
list can be marked as completed (which crosses it out and gives it a
different look) or deleted entirely. Tasks are only stored in memory
while the page is open — nothing is saved after a refresh.

# How to Run

1. Download or clone this repository.
2. Open the folder in Visual Studio Code (or any editor).
3. Open `index.html` in a web browser (you can just double-click the
   file, or use the "Open with Live Server" extension in VS Code).
4. Type a task name, pick a priority, and click **Add Task**.

No build steps, servers, or installations are required — it's plain
HTML, CSS, and JavaScript.
